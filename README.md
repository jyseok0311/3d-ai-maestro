# AI Maestro · 교직원 AI 교육 운영 관제

교직원·실무자 대상 **AI 마에스트로** 교육과정의 운영 현황을 실시간 전략(RTS) 게임처럼 내려다보며 관제하는 3D 앱입니다.
장전·양산·밀양 3개 캠퍼스의 AI교육관에서 교육 차수(수강생 그룹)가 이동하고, 교육실에서 강의·실습을 받고,
실습 지원 로봇이 교보재를 나르는 모습을 한 화면에서 봅니다.
React Three Fiber + drei + Zustand + TypeScript + Vite.

- **라이브 데모:** https://3d-ai-maestro.vercel.app
- **GitHub:** https://github.com/jyseok0311/3d-ai-maestro

`main` 브랜치에 푸시하면 Vercel이 자동으로 프로덕션에 배포합니다.

![AI Maestro 화면: 장전캠퍼스 AI교육관의 3D 뷰, 상단 KPI 바, 좌측 필터·교육 세션 목록](docs/screenshot.png)

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck  # 타입 체크
npm run build      # 프로덕션 빌드 (dist/)
```

## 조작

| 동작 | 입력 |
| --- | --- |
| 지도 이동 | 마우스 드래그 |

## 화면 구성

| 3D 요소 | 의미 |
| --- | --- |
| 교육 차수 (사람 그룹) | 한 반의 수강생. 휴식 → 이동 → 입실 대기 → 입실 → 강의/실습 → 퇴실 순서로 움직이며, 교육실에서는 책상에 앉습니다. 색은 과정(AI 기초·프롬프트 실무·업무 자동화·데이터 분석) |
| 교육실 포드 | AI교육관 앞 유리 강의실 6개. 교육 중이면 스크린이 켜지고 상태 표시등 색이 바뀝니다 |
| 실습 지원 로봇 | 교보재를 교육실 입구로 나르는 조교 로봇. 배터리가 부족하면 충전소로 갑니다 |
| 교보재 보관함 | 노트북·실습 키트·교재 등. 상자 색은 품목 종류, 빨간 상자는 재주문점 이하 |

**KPI:** 정시 입실률 · 교육실 사용 · 진행 중 차수 · 부족 교보재
**필터:** 지연 세션만 보기, 교육 차수 상태별 보기

## 코드 구조

| 폴더 | 내용 |
| --- | --- |
| `src/data/` | 데이터 모델(Campus·Room·Cohort·Assistant·Material·Session), 캠퍼스 배치도, 시드 데이터(캠퍼스 3, 교육실 18, 차수 12, 로봇 8, 교보재 40, 세션 25) |
| `src/sim/` | 2초마다 실행되는 순수 함수 시뮬레이션 (바뀐 레코드만 교체) |
| `src/store/` | Zustand 스토어, KPI·필터 계산 |
| `src/scene/` | 3D 씬: 카메라(드래그·휠·맵 경계·캠퍼스 이동), 보관함 인스턴싱, 수강생 인스턴싱, 교육실·로봇 모델 |
| `src/ui/` | 상단 바, 필터·세션 목록, 상세 패널, 범례 |

### 데이터 모델 요약
- `Campus`가 루트이며 나머지 엔티티는 모두 `campusId`로 캠퍼스에 속합니다.
- `Cohort`↔`Room`(`roomId`/`cohortId`), `Cohort`↔`Session`(`sessionId`/`cohortId`)은 양방향 1:1 참조입니다.
- `Session.lines`가 수업에서 배부하는 `Material`을 수량과 함께 참조합니다(N:N).
- `Assistant`는 지원 중인 `Session`을 선택적으로 참조하고, 캠퍼스 내 좌표로 위치를 가집니다.

> 시뮬레이션 시간은 압축되어 있어(세션 시작까지 수십 초) 정시·지연 입실이 짧은 시간 안에 계속 발생합니다.
> 캠퍼스·부서·인물·교보재는 모두 시연용 가상 데이터입니다.
